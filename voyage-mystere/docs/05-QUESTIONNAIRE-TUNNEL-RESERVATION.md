## 🎯 QUESTIONNAIRE DE PERSONNALISATION (15 Questions)

### Design & UX

**Principe:**
- 1 question par écran (mobile-first)
- Progression visuelle (barre + "Question 3/15")
- Possibilité de revenir en arrière (flèche ←)
- Sauvegarde automatique (si refresh, reprend où il en était)
- Animations douces entre questions
- Illustrations ludiques pour chaque question

### QUESTION 3: RYTHME IDÉAL

**Écran:**
```
[Illustration: Échelle de rythme - tortue → lapin]

**Options (radio buttons avec descriptions):**

  ```

  ```

- 🏃 **Action & Découvertes**
  ```
  Debout tôt, activité matinale, déj' rapide, visite/activité l'après-midi,
  apéro, resto, peut-être sortie le soir. On optimise chaque moment !

  Parfait pour : Rentabiliser le week-end, voir un max de choses
  ```

- ⚡ **Intense / Aventuriers**
  ```
  Réveil 6h, rando ou activité intense, visite express, nouvelle activité,
  exploration nocturne. Sommeil = à la maison !

  Parfait pour : Les sportifs, les hyper-actifs, les "j'ai trop d'énergie"
